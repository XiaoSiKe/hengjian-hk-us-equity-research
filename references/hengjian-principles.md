# 衡鉴原则：平衡与秩序

「衡」衡量证据的分量与决策的代价；「鉴」检查来源、口径和自己的偏见。道家文本在这里是**研究纪律的启发**，不是价格预测模型，也不能替代财报、估值或风险数据。

| 启发 | 在投研中的可执行动作 | 不可推导的结论 |
| --- | --- | --- |
| 《道德经》[第四十章](https://ctext.org/dao-de-jing/zh)的「反者道之動」 | 对最强论点做反向检验：它依赖什么，哪项事实可以推翻它？同样检验空头论点。 | 不表示股价一定均值回归、涨多必跌。 |
| [第四十四章](https://ctext.org/text.pl?if=en&node=11635&show=parallel)的「知止不殆」 | 在价格、币种、股数、来源或权限不可靠时停止相应计算；把等待更多证据写成明确选项。 | 不表示永不行动，也不提供固定仓位。 |
| [第六十三章](https://ctext.org/text.pl?if=en&node=11654&show=parallel)的「圖難於其易」 | 从代码、日期、单位、期间这些小处开始，逐关建立大判断；先排除简单错误。 | 不表示一个检查表就能解释复杂企业。 |
| 「為無為」的思想 | 保留「等待核实／暂不调整」作为真实建议，说明等待什么新证据；避免为输出建议而强行交易。 | 不等于消极持有，也不暗示市场会奖励等待。 |
| [第五十八章](https://ctext.org/dao-de-jing/zh)的祸福相依 | 对乐观情景写出它会带来的新风险，对悲观情景检查可能的修复路径；把二阶后果放进情景。 | 不表示利空必变利好，或股价必反转。 |
| 爱比克泰德[《手册》开篇](https://www.gutenberg.org/files/45109/old/45109-h/45109-h.htm)区分可控与不可控 | 把来源核验、估值假设、组合暴露和复核纪律作为可控输入；把短期价格结果视作不确定输出。 | 不表示可以忽略价格、现金需要或真实损失。 |

## 衡鉴五序

1. **定界：** 明确发行人、股类、市场、ADR 换算、投资问题和截止时间。身份未定，停止每股比较。
2. **验真：** 把决定结论的数字和事实逐项放进证据表，核对原始来源、期间、币种和发布时间。关键事实不明，降级结论。
3. **观势：** 分析商业机制、现金产生与资本配置；区分已发生变化和管理层／市场对未来的说法。
4. **反照：** 各写最强支持与反面论据，并列出使双方失效的事实。平衡是公平检验，不是正反意见强行各占 50%。
5. **知止：** 选择合适估值方法和情景；明确输入缺口、价格隐含条件、下一次核查点，以及哪些结论现在不能下。

从投资方法借镜时，按[投资方法视角](investor-lenses.md)选择与公司有关的少数问题。哲学和大师观点只帮助发现盲点；决定建议的仍是当前证券、当前价格与可核事实。

## 结论措辞

结论强度受最弱关键证据约束。资料充足时可写「建议……，在这些假设下情景区间为……」；关键数据冲突时给出「等待核实」建议并写明冲突；只有叙事没有可核数据时指出应观察的事实。不要以哲学词汇掩盖证据缺口。
