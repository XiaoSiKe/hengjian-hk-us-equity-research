# 研究方法

本表只决定**内部研究重点**。无论走哪条路径，对用户都交付同一份[衡鉴建议单](output-contract.md)，不拆成多份报告或工具结果。

## 模式选择

| 请求 | 交付重点 |
| --- | --- |
| 速览 | 证券身份、最近变化、三项关键证据、两个关键风险、待核实事项。缺数据也能给出有界结论。 |
| 深度研究 | 生意如何赚钱、竞争与护城河、财务质量、管理层和资本配置、估值、正反论点。 |
| 财报解读 | 同口径同比／环比、现金与利润差异、指引变化、一次性项目、核心业务指标及下一季验证点。 |
| 同业比较 | 先定义相同业务与会计口径，再并排比较增长、利润、现金、资本效率、杠杆、稀释与估值。 |
| 持仓复核 | 只使用用户自愿提供的成本、数量、投资期限和风险约束；评估论点变化、集中度、流动性、潜在损失及行动条件。 |
| 论点更新 | 保存原论点、当时依据、可证伪指标；新证据出现时标记维持、削弱或失效，并说明原因。 |
| 观点／研报核验 | 把影响结论的论断拆成证据表，区分已核实、冲突、无法核实、过时和已推翻。读[证据审查](evidence-review.md)。 |
| 可疑荐股检查 | 当用户带来群聊、老师、内幕、保赚或紧迫跟单信息时，核查信息来源与动机、证券流动性、融资稀释、监管与审计披露；读[证据审查](evidence-review.md)。 |

## 研究顺序

1. **身份与时间。** 确认发行人、上市地、股类、ADR 比例、报告币种、交易币种、研究截止时点。双重上市的两条证券价格不可直接比较；先换算汇率及每单位代表的普通股数。
2. **业务。** 回答客户是谁、收入由什么驱动、毛利与现金由什么产生、竞争优势能否被价格或技术变化侵蚀。把管理层陈述与已实现数据分开。
3. **财务质量。** 核对收入、利润、经营现金流、资本开支、自由现金流、债务、现金、股本及股权激励；查明重大一次性项目、并购、会计口径变化和现金转换率。单季与全年分别处理；10-Q 的现金流常为年初至今累计值，不把它直接当单季现金流。
4. **估值。** 先按[行业判断](sector-lenses.md)确认方法。对现金流稳定的一般企业可用 DCF；对盈利、收入或 EBITDA 适合比较的公司可用相应倍数。说明为什么选该方法，展示悲观／基准／乐观假设及敏感点。有可核价格时，可反推市场价格隐含的增长假设，并将它与自己的假设比较。净现金、股数、ADR 换算和 FX 由可追溯输入提供。
5. **反证。** 写出最强的空头论据；找能够推翻它的证据，也找能够推翻多头论据的证据。技术指标、社交热度、机构持仓只能当线索，不单独证明价值或未来收益。

## 方法借鉴的边界

可把“生意本质、护城河、逆向思考、安全边际”作为提问角度，不模拟名人发言，也不把任何项目的固定评分当成事实。多角色讨论最终必须回到同一份证据清单。任何历史回测须说明样本、费用、滑点、幸存者偏差、时间穿越和样本外检验；本 Skill 默认不生成交易信号。

需要进一步挑战论点时，按[投资方法视角](investor-lenses.md)选择至多两个与公司有关的提问角度；不要把不同大师的结论平均成一个分数。结论统一由[建议形成规则](recommendation-policy.md)与当前事实、价格决定。

研究与持仓讨论要分开：研究可以提出条件性假设；仓位大小、杠杆、税务和个人损失承受能力依赖用户信息，缺失时只列需核查的风险。用户没有明确要求保存时，论点状态卡留在答复中，不落盘。

持仓风险复核至少核对单票集中度、行业与因素重叠、流动性、外汇敞口、ADR／上市结构、负债与最大可承受损失。用户未提供全组合时，只说明已知持仓的局部风险，不推断组合总风险。
