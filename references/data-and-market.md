# 数据与市场规则

## 来源次序

1. **美股申报：** 直接查看 [SEC EDGAR](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) 的具体 10-K、10-Q、20-F、6-K，以及发行人投资者关系材料。公开页面足以支撑常规报告；本地 `sec_facts.py` 只是可选的内部提取器，运行不了就用已读取的原始文件核对。
2. **港股公司事实：** 使用公司投资者关系网站上的年报、业绩公告与演示材料，以及用户提供的文件。需要交易所公告时可提示用户自行在 HKEXnews 检索；不要自动抓取或对港交所网站做文本数据挖掘，[HKEX 条款](https://www.hkex.com.hk/Global/Exchange/Terms-of-Use?sc_lang=en)对此有限制。
3. **行情：** 从当前可直接访问且显示报价时间的可靠公开来源核价，必要时交叉核对；已有只读行情工具可以使用，但绝不把它变成用户的配置任务。不得把延迟或时点未知的报价称为实时。
4. **预期与新闻：** 作为 `[C]` 或待验证线索，不能替代监管申报；区分新闻发布时间与事件发生日。

内部记录 `source_url`、`published_at`／`filed_at`、`retrieved_at`、原始单位、币种及报价时点。建议单只展示影响结论的来源与时点。一个来源不可用时换用其他可核来源；不要要求用户安装、登录或提供数据接口配置。

### 证据的层级与用途

| 来源 | 可支持什么 | 还要核查什么 |
| --- | --- | --- |
| 原始申报、审计财报、公司业绩公告 | 报表数字、股本、管理层正式披露的事件 | 报表是否重述、后来是否有新公告、管理层说法与事实的区别 |
| 有时点的行情与汇率来源 | 特定时点的价格、币种和市场状态 | 盘中／盘后／收盘、延时、复权口径与是否为同一证券 |
| 券商一致预期、行业研究、新闻 | 市场期待、竞争线索、事件背景 | 预期统计日期、原始事件及是否存在商业利益 |
| 社交帖子与截图 | 值得追查的论点 | 作者、原始出处、时间和可观察的证据；不能直接升级为 `[F]` |

一项事实被多个转述网站重复，不算多源验证。真正的交叉核查需要口径独立、来源明确；来源发生冲突时记录各自的期间、币种、会计定义和发布时间，再决定是否可调和。

## 市场差异

- 美股代码为交易所代码；SEC 的 CIK 指向发行人，不保证一家公司只有一个证券。港股代码保留前导零，统一写成 `0700.HK` 这类格式；Futu 调用时转为 `HK.00700`。
- 港股交易价常用 HKD，财报可用 HKD、CNY、USD；美股 ADR 交易价常用 USD，财报币种可能不同。不要混用报告币种和交易币种。FX 应注明方向，例如“1 CNY = x USD”。
- ADR 比例写成“1 ADR = n 普通股”；估值每股价格是否要乘 `n` 取决于股数口径。不能仅凭代码推断比例，必须查发行人／存托协议。
- 对比年度或季度时同时检查财年结束日、期间长度、报表重述、拆股、回购和稀释。市值、企业价值和每股估值都须匹配同一天附近的股数与价格。
- 财报正文、新闻与行情的更新时间不同；研究截止日以后公布的材料不得倒填到历史分析。缺少确认信息时标 `[U]`，不要补造。
- `sec_facts.py` 的历史截止精度是**日期**，SEC Company Facts 中的 `filed` 也只有申报日期。若用户指定某日的具体时刻，需核实该文件当时的实际发布时间；不能仅靠该脚本证明日内可见性。

### 最新性与可比性

「最新」指**研究截止时已经公开、且尚未被更近披露取代**，并非把所有数字都强制要求在同一周发布。年报、季报、报价和新闻可有不同日期；报告页眉分别说明。节假日或休市时使用最近一个可核交易时点，不把上一交易日收盘价写成正在跳动的现价。

同比与同业比较先核实际起止日、财年口径和合并范围。公司便利换算的美元列不能替代原始报告币种；每股指标还要匹配拆股、回购和增发后的股数。市场报价无法独立核实时，可以做生意分析，但与现价有关的结论须缩小。

## 停止条件

- 无可核实现价：不计算潜在收益、安全边际、买入区间或止盈止损，但仍交付以业务和风险为依据的「等待核实」建议单。
- 无可核实股数、净现金或必要 FX／ADR 比例：不输出每股估值。
- 关键数据矛盾且无法调和：并列展示来源及差异，暂停对应定量结论。
- 来源不可直接使用：改用其他可核的公开来源、公司自有披露或用户提供材料；不要转成安装或授权说明。
