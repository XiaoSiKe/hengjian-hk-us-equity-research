# 参考项目与使用边界

截至 2026-09-26 核对。这里只记录设计启发和仓库许可证，不复制第三方源码、实例报告或市场数据。许可证与接口条款会变化，重新分发前需复核。

| 项目 | 仓库许可证 | 借鉴点 | 边界 |
| --- | --- | --- | --- |
| [UZI Skill](https://github.com/wbh604/UZI-Skill) | MIT | 深度研究与可疑荐股信息的风险排查 | 不照搬投资者角色、量化权重或模板 |
| [FinRobot](https://github.com/AI4Finance-Foundation/FinRobot) | Apache-2.0 | 计算与叙述分离、数字溯源 | 不打包其框架和模型 |
| [TradingAgents](https://github.com/TauricResearch/TradingAgents) | Apache-2.0 | 基本面、情绪和风险的相互质疑 | 不把多角色共识当证据 |
| [AI Hedge Fund](https://github.com/virattt/ai-hedge-fund) | MIT | 可比较的多视角研究 | 原项目为教育概念验证，不采用实盘主张 |
| [AI-Trader](https://github.com/HKUDS/AI-Trader) | 未标明 | 社区信号须独立验证的提醒 | 不复制代码、不注册、不跟单、不交易 |
| [global-stock-data](https://github.com/simonlin1212/global-stock-data) | Apache-2.0 | 数据层、来源分级与合规标签 | 不复制其端点实现；各数据源条款独立检查 |
| [Buffett Oracle Analyzer](https://github.com/cbkkevin/buffett-oracle-analyzer) | MIT | 企业质量、所有者盈余、估值方法的研究问题 | 不采用固定分数或例子价格 |
| [ai-berkshire](https://github.com/xbtlin/ai-berkshire) | MIT | 生意本质、护城河、反证、安全边际 | 不模拟名人原话或复制完整方法文本 |
| [InvestSkill](https://github.com/yennanliu/InvestSkill) | MIT | 逐项论断核验、空头反证、论点状态卡、报告复核 | 不复制其固定分数、买卖信号或原文模板 |
| [stock-analysis-skill](https://github.com/Arthur19940725/stock-analysis-skill) | 未标明 | 证据标签与数据不足时降低结论精度 | 仅借鉴原则，不复制实现 |
| [Futu Agent Hub](https://github.com/FutunnOpen/futu-agent-hub) | 未标明 | 只读港美行情接口方向 | 仅调用用户已有权限的官方 API，不复制其 Skill |
| [hk-us-market-skill](https://github.com/shouldnotappearcalm/hk-us-market-skill) | 未标明 | 回退数据源和市场代码规范 | 不复制源码或默认免密抓取链 |

用户第二张图片是社交讨论截图，没有策略原文。它只启发“观点溯源与反证、财报质量分析”两项需求，不构成投资方法的来源。

「衡鉴」的哲学措辞参考[《道德经》原文](https://ctext.org/dao-de-jing/zh)，在[衡鉴原则](hengjian-principles.md)中明确区分文本启发与可验证的金融结论。

新增[投资方法视角](investor-lenses.md)使用[伯克希尔股东信](https://www.berkshirehathaway.com/letters/1986.html)、[Oaktree 的 Howard Marks 备忘录](https://www.oaktreecapital.com/insights/memo/risk-revisited)、[Damodaran 的 NYU 资料](https://pages.stern.nyu.edu/adamodar/New_Home_Page/numbers%26narrative.htm)、[Fundsmith 投资者手册](https://www.fundsmith.co.uk/media/t5vjdlkm/fsf-owners-manual.pdf)与[Vanguard 投资原则](https://corporate.vanguard.com/content/dam/corp/research/pdf/vanguards_principles_for_investing_success.pdf)作一手参考；只保留能改变核查问题的思想，不复制原文或假装这些作者为具体股票背书。

[行业判断](sector-lenses.md)引用 FDIC／HKMA、NAIC、Nareit、FDA 等机构的指标定义。来源的职责是规定口径；个股数字仍须来自该公司与当前时点的披露。
