# 投资方法视角：用于提问，不用于代言

按公司最重要的争议选 **1–2 个**视角，用它们改进证据核查；最终仍由同一套[建议形成规则](recommendation-policy.md)裁决。不要写「某大师投票买入」、模拟本人发言或把名气当事实。

| 视角与一手材料 | 在建议单中追问 | 常见误用 |
| --- | --- | --- |
| **巴菲特／芒格：企业质量与所有者现金。** [伯克希尔 1986 年股东信](https://www.berkshirehathaway.com/letters/1986.html)讨论 owner earnings；[1989 年股东信](https://www.berkshirehathaway.com/letters/1989.html)复盘低价买差生意的错误。 | 报表利润有多少真正可分配或再投资？资本开支与股权激励之后，股东得到什么？优势能维持多久？ | 把低 P/E 当安全边际；把财务比率当护城河证明。 |
| **霍华德·马克斯：价格、风险与周期。** [Oaktree《Risk Revisited》](https://www.oaktreecapital.com/insights/memo/risk-revisited)与[《Thinking About Macro》](https://www.oaktreecapital.com/insights/memo/thinking-about-macro)。 | 当前价格补偿了哪些可能的损失？市场共识是否已反映在价格里？结论是否依赖难以证实的宏观预测？ | 用「周期」一词预测精确顶部或底部；只看波动率而忽视永久性损失。 |
| **达摩达兰：叙事必须落到数字。** [NYU《Narrative and Numbers》资料](https://pages.stern.nyu.edu/adamodar/New_Home_Page/numbers%26narrative.htm)。 | 增长故事要求多大的市场份额、利润率和再投资？这些数字能否与行业规模及竞争同时成立？ | 先填高增长率，再写故事为它辩护。 |
| **Terry Smith：好生意、价格与耐心。** [Fundsmith 的投资者手册](https://www.fundsmith.co.uk/media/t5vjdlkm/fsf-owners-manual.pdf)。 | 高资本回报能否跨周期保持？买入价是否吞噬好生意带来的长期收益？当前有什么必要行动？ | 因公司好就接受任何价格；把「不行动」当成永远不复核。 |
| **Bogle／Vanguard：机会成本与组合秩序。** [Vanguard 投资原则](https://corporate.vanguard.com/content/dam/corp/research/pdf/vanguards_principles_for_investing_success.pdf)。 | 承担单只股票的集中风险后，机会相对分散、低成本基线是否值得？费用、税务与组合重叠影响什么？ | 用指数平均表现替代个股研究；未得到用户组合信息就声称适合重仓。 |

若公司与这些视角的前提不符，直接舍弃对应视角。生物科技早期项目不能用稳定 owner earnings 论证；银行不能机械使用普通工业企业的 FCFF。视角在报告中只需以具体问题或证据体现，不必列大师名单。

## 如何把视角变成有用的报告段落

1. **先找当前争议。** 是利润与现金不一致、增长叙事难量化、估值依赖高情绪，还是持仓与组合目标冲突？只挑能触及该争议的视角。
2. **提出可回答的问题。** 例如「扣除维持性支出与股权激励后，股东现金创造是否增长」，胜于写「巴菲特会喜欢这家公司」。
3. **找本公司的证据。** 用报表、附注、产品指标、竞争和价格数据回答；若没有，标为待验证假设。
4. **检查视角的反例。** 长期高 ROIC 也可能伴随过高买价；价格低也可能反映永久性损失；指数比较也不能否定少数真实优势。

### 三种常见搭配

- **成熟消费或软件企业：** 巴菲特／芒格的股东现金问题，加 Terry Smith 的质量和价格问题。重点看现金转换、再投资与买价，而非只数品牌和用户。
- **高增长故事企业：** 达摩达兰把产品叙事转换为份额、利润率和资本需求，再用霍华德·马克斯追问现价是否补偿实现路径中的风险。
- **用户准备集中持有：** 企业研究照常做，额外用 Bogle／Vanguard 的机会成本视角检查单票风险、费用及相对于分散方案的理由。未获得用户完整组合时，只说可确认的局部风险。

大师观点的任务是拓宽问题集合；一只证券的建议仍由当期事实、行业方法、价格和[建议形成规则](recommendation-policy.md)决定。
