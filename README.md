# ⚖️ 衡鉴｜港美股投研

### 把股票建议写成能复核、能反驳、也能更新的一份报告。
### Hengjian · Hong Kong & U.S. Equity Research

给出一个港股或美股代码，衡鉴会把**公司、财报、价格、反面证据与行动条件**放到同一张研究桌上，最终只交付一份「衡鉴建议单」。你先看到结论，再看到它依据什么、最可能错在哪里，以及什么新事实会改变它。

衡鉴面向普通美股、港股和 ADR／双重上市证券。默认采用一般权益投资者的 12–36 个月研究视角；有持仓、期限和组合约束时再按你提供的信息调整。它不会要求你接入券商、申请数据 API 或准备一套交易环境。

```text
确认买的是什么 → 核实能知道什么 → 分析生意与现金 → 反向挑战论点
        → 衡量价格和悲观损失 → 写出唯一建议与改变建议的条件
```

## 🧭 它能帮你做什么

用户只需要讲眼前的问题；衡鉴选择内部研究路径，交付格式始终是一份建议单。

| 场景 | 衡鉴重点处理 | 报告里最重要的结果 |
| --- | --- | --- |
| 🔍 **第一次看一只股票** | 核对发行人、代码、主要业务、最新披露与报价 | 一句行动建议、三项决定性依据、下一次核查点 |
| 📑 **财报刚发布** | 对齐季度与年度口径，拆开一次性项目、现金和管理层指引 | 这份财报改变了原论点的哪一部分 |
| ⚖️ **觉得它贵或便宜** | 用适合该行业的方法做悲观／基准／乐观情景 | 当前价格要求公司实现什么，风险补偿是否足够 |
| 🧩 **比较两家公司** | 先选真正可比的业务和期间，再比较增长、现金、资本效率与价格 | 哪些差异影响投资判断，哪些数字不能直接比 |
| 🌐 **美股 ADR 与港股双重上市** | 核 ADS 比例、股类、汇率、交易时点与转换成本 | 同一普通股经济权益下的可比分析 |
| 📌 **已有持仓** | 分开成本价与企业价值，复核论点、集中度、流动性和最大损失 | 继续持有、暂停加仓或考虑减仓的条件 |
| 🧪 **看到荐股帖或研报** | 逐项拆出可证伪论断，检查来源、作者动机及最强反证 | 已核实、冲突、无法核实分别是什么 |
| 🔁 **继续跟踪老论点** | 更新关键指标、催化剂和失效条件 | 论点仍成立、被削弱、已失效或证据不足 |

它不会让每一条路径产出一份独立文档。财报、比较、估值和持仓都是**同一份建议单的研究材料**。[研究模式与问题清单 →](references/research-methods.md)

## 🧱 系统全景：三层研究闭环

衡鉴先知道自己买的是什么，再判断企业如何创造价值，最后决定当前价格是否值得承担风险。三层共用同一份证据，不会各写各的结论。

```text
事实层   身份与时点 ── 原始披露 ── 行情、币种与来源核对
          ↓
研究层   商业机制 ── 财务和行业指标 ── 估值、反面论证
          ↓
决策层   风险收益门槛 ── 唯一行动建议 ── 出稿复核
          └──────── 新披露和价格变化，回写事实与论点 ────────┘
```

### 事实层｜先把口径放对

| 内部节点 | 必须确认 | 错了会怎样 |
| --- | --- | --- |
| ① 证券身份 | 发行人、交易所、普通股／ADR、存托比例 | 可能把不同证券的价格直接比较 |
| ② 披露与报价 | 最近可用的年报、季报、公告，报价的盘中／收盘时点 | 可能把旧事实和新价格拼成一个假结论 |
| ③ 证据标签 | 事实、预期、分析假设、派生计算、未知项 | 可能把市场传闻写成已证实收入 |

### 研究层｜让故事和数字互相约束

| 内部节点 | 核心提问 | 产出给决策层 |
| --- | --- | --- |
| ④ 生意与竞争 | 谁付费、为何留下、优势靠什么维持？ | 能被新证据推翻的经营论点 |
| ⑤ 财务与行业 | 利润转成现金了吗？银行、REIT、生物科技该用什么尺子？ | 同口径趋势、资产负债与专用指标 |
| ⑥ 估值与反证 | 增长需要多少投入？最强空头论据是什么？ | 三情景、价格隐含条件、悲观损失 |

### 决策层｜把研究压缩成一页能用的话

| 内部节点 | 判据 | 面向读者的交付 |
| --- | --- | --- |
| ⑦ 建议门槛 | 身份、重大风险、证据、行业方法、价格、损失顺序检查 | 可考虑买入／等待／回避／等待核实 |
| ⑧ 触发条件 | 哪项可观察事实会让建议改变？ | 值得行动、应止步、下次复核的条件 |
| ⑨ 出稿复核 | 来源能否打开？数字可否复算？最强反证有没有被回应？ | 一份自洽的建议单 |

入口 [SKILL.md](SKILL.md) 只保存共同规则和路由；识别任务后再读取相关的[参考协议](references/)。使用者看到一个 Skill，Agent 也无需每次把所有行业手册一起载入。

## 🗣️ 衡鉴怎么讲：先给建议，再讲判据

衡鉴用投资者能检查的语言表达，不用长段术语代替判断。

| 容易让人听不懂的说法 | 衡鉴会说清楚 |
| --- | --- |
| “估值存在一定安全边际” | “现价低于基准情景；悲观情景可能损失多少，主要取决于哪两项假设。” |
| “业绩增长质量较高” | “收入增长是否来自真实需求；利润增加后，经营现金和每股权益是否也增加。” |
| “建议关注风险” | “若下季客户留存再下降且销售费用继续上升，当前增长论点就要重估。” |
| “尚待数据验证” | “缺少可核的现价，今天可以判断生意变化，不能负责任地给买入区间。” |

一份可用的建议单让你回答四个问题：**现在建议什么？依据是哪几项？最可能错在哪里？什么变化会让我改主意？** 答不清就继续取证或缩小结论。[报告契约 →](references/output-contract.md)

## 📄 最终只有一份「衡鉴建议单」

建议单第一页先放决定，细节随后展开：

```text
衡鉴建议单｜公司（交易所:代码）
研究截至 · 研究期限 · 报价时点/币种 · 所用财报期间 · 股类/ADR 关系

行动建议：可考虑买入 / 等待 / 回避 / 等待核实
适用条件：一般研究，或基于用户主动给出的持仓与约束
三项依据：业务和现金｜价格或市场预期｜最大风险
把握程度：高 / 中 / 低——表示证据完整度，不是上涨概率

01  公司怎样赚钱，优势和竞争会怎样变化
02  财报利润是否变成现金，债务、股本与资本开支有什么压力
03  悲观/基准/乐观情景，价格已包含什么预期
04  最强反面论据，以及什么事实能推翻它
05  行动条件、止步条件与下一次复核事件
06  来源、时点、口径和真正影响结论的数据缺口
```

有足够输入才给每股价值、现价差距和买入区间。若价格、股数、汇率或行业核心指标无法核实，报告仍会完成，行动建议降为「等待核实」，并指出下一步最值得找的那项证据。不会用模型生成的数字伪装市场报价。[输出格式细则 →](references/output-contract.md)

## ⚖️ 建议形成：先过关，再谈价格

| 建议 | 在什么条件下成立 | 报告必须解释 |
| --- | --- | --- |
| **可考虑买入** | 经营论点仍成立，来源和行业方法可靠；现价低于基准情景，悲观损失有依据且不大于基准上行 | 为什么当前缓冲足够；何时会转为等待或回避 |
| **等待** | 生意可能不错，但价格已接近基准价值、悲观损失偏大或关键催化尚未兑现 | 价格或经营证据需要怎样变化 |
| **回避** | 有证据支持重大永久性损失风险、论点失效，或价格不低于可信的乐观情景 | 具体风险从哪里来；低价为何不能消除它 |
| **等待核实** | 身份、报价、股数、币种或决定性行业指标缺失、过时或冲突 | 最影响判断的未知项，以及核实后怎样重算 |

已证实的重大损失风险排在价格之前；一家公司“跌了很多”不是独立的买入理由。衡鉴没有通用的 20% 安全边际，也不把多个投资大师的意见加权成分数。内部的[建议规则](references/recommendation-policy.md)保持一个结论；出稿前再做[事实与推理核验](references/report-qa.md)。

### 同样的数字，也要看它有多脆弱

假设某证券现价 100、悲观价值 80、基准价值 130，则基准上行是 30，悲观下行是 20。这只是一个**虚构的算术示例**：即使 30 大于 20，若现金流未经证实、行业方法错配或存在不可承受的尾部风险，仍不应直接生成买入建议。

DCF、P/E、P/B、P/FFO 或 EV/收入等方法各有适用前提；现价可核时可以反推它对增长的要求，但反推值是**市场价格隐含的条件**，不是衡鉴预测公司一定达到的增长率。[行业方法 →](references/sector-lenses.md)

## 🧩 行业有不同的尺子

| 类型 | 先看什么 | 避免什么 |
| --- | --- | --- |
| 一般盈利企业 | 资本回报、利润到现金的转换、再投资与债务 | 因 P/E 低就叫便宜 |
| 银行 | 存款成本、净息差、贷款质量、拨备、CET1 和流动性 | 把存款当工业企业债务，硬套 FCFF |
| 保险 | 承保质量、准备金、投资资产与法定资本 | 把财险综合成本率用在寿险 |
| REIT | FFO、租约、维护支出、分派覆盖和再融资 | 只拿会计净利润或未核对的 AFFO 作判断 |
| 开发阶段生物科技 | 试验终点、监管节点、现金跑道与潜在稀释 | 将早期项目按稳定获批收入估值 |
| 持续亏损成长企业 | 留存、单位经济、毛利、经营杠杆与现金消耗 | 默认负现金流会自行转正 |

混合集团先拆业务再合并；双重上市先核 ADS 比例、汇率和报价时点，再比较**同一普通股经济权益**。行业指标、估值边界和一手定义见[行业判断](references/sector-lenses.md)。

## 🔎 证据纪律：先原文，后推断

美股优先查 SEC 申报及公司投资者关系材料；港股优先查公司年报、业绩公告和演示材料。每项决定结论的数字都保留**来源、发布时间、财务期间、单位、币种**；行情另写盘中／盘后／收盘及报价时间。新闻、研究报告和社交帖子能提供线索，不能直接把未核实说法升级为已发生事实。

| 标记 | 含义 | 例子 |
| --- | --- | --- |
| `[F]` | 经原始材料核对的事实 | 审计报表中的收入及期间 |
| `[C]` | 外部预期或共识 | 具名机构、具体日期的一致预期 |
| `[E]` | 模型估计 | 对下一年利润率的估算 |
| `[A]` | 分析者假设 | 悲观情景采用的增长率 |
| `[D]` | 可复算的派生结果 | 同比、自由现金流、每股情景价值 |
| `[U]` | 尚未查明 | 无法核实的报价或股数 |

同一个数字在三家网站被转述，仍可能只有一个原始来源。两份可信材料若相冲突，衡鉴会展示差异、期间和可能的定义原因；「无法核实」也不同于「已证伪」。来源、时点与港交所网站自动访问边界见[数据规则](references/data-and-market.md)。

## 🧠 方法底座：大师与哲学只负责提出问题

衡鉴从巴菲特／芒格的股东现金与企业质量、霍华德·马克斯的风险补偿、达摩达兰的叙事—数字约束、Terry Smith 的质量与买价、Bogle 的机会成本中，挑与当前公司**最相关的 1–2 个问题**。它不会模拟本人发言，也不会写「五位大师投票买入」。[一手出处及误用边界 →](references/investor-lenses.md)

| 思想 | 在衡鉴中的可执行动作 |
| --- | --- |
| 道家「反照」 | 主动找能推翻多头论点的事实，也检验空头最可能错在哪里 |
| 「知止」 | 关键来源、股数或汇率不可靠时停止相应计算，并告诉读者下一步查什么 |
| 「由细而大」 | 先核代码、期间和单位，再推出每股价值与行动建议 |
| 可控与不可控 | 控制来源核验、假设和复核纪律；不承诺控制短期股价结果 |

哲学是研究纪律，**不是预测市场的因果模型**。[衡鉴原则 →](references/hengjian-principles.md)

## 🛡️ 可信度、隐私与边界

- **数据不足仍交付。** 只有可支持的分析进入建议单；未核目标价和上涨胜率不会补造。
- **不把工具变成门槛。** 不要求用户配置 API、券商、环境变量或插件。可用的本地脚本只负责确定性计算。
- **不自动保存个人信息。** 持仓成本、数量和组合信息只用于当前请求；用户没有要求保存时不落盘。
- **不执行交易。** 不登录交易账户、不下单、不跟单、不发布交易信号。
- **遵守来源使用边界。** 不自动抓取港交所网站；港股研究优先使用公司自己发布、用户提供或其他可合法使用的材料。

衡鉴默认提供**一般研究建议**。当你提供持仓与明确约束时，它能把建议写得更贴近这次决策，但不会自行猜测你的完整财务状况。
