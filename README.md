## 为什么做衡鉴

一份有用的投研报告，应当让读者同时看见 **行动建议、关键证据、最强反证，以及改变建议的条件**。

「衡」衡量企业质量、价格与风险；「鉴」核实资料，也检查自己的判断。衡鉴把财报、估值、同业和持仓问题收束成**一份建议单**。它会研究，也会在关键事实不足时明确建议等待；不会为凑齐报告而编造价格或目标价。

## 快速开始

### 安装

```bash
npx skills add XiaoSiKe/hengjian-hk-us-equity-research
```

也可以把本仓库克隆到 Codex 的 Skills 目录：

```bash
git clone https://github.com/XiaoSiKe/hengjian-hk-us-equity-research.git \
  ~/.codex/skills/hengjian-hk-us-equity-research
```

### 使用

在对话中直接说：

> 用衡鉴给我一份腾讯 0700.HK 的建议单。

或者指定视角与问题：

> 用 `$hengjian-hk-us-equity-research` 分析 BABA 和 9988.HK：先核对 ADS 换算，再判断当前价格是否值得考虑。

正常出报告**无需配置券商账户或专用行情 API**。Agent 会使用它当前可访问的公开申报、公司材料和带时间戳的报价；本仓库的 Python 脚本只是可选的内部计算工具。

## 你会收到什么

> **衡鉴建议单｜公司（交易所:代码）**
> 研究截至：日期与时区 · 报价：价格、币种与时点 · 财报：所用期间
>
> **行动建议**　可考虑买入 / 等待 / 回避 / 等待核实
>
> **一句话理由**　当前价格与企业质量、悲观风险之间的关系
>
> **把握程度**　高 / 中 / 低，解释的是证据质量，不是上涨概率

报告随后说明：

1. 公司如何赚钱，竞争优势还能维持多久；
2. 收入、利润、现金流、资本开支、债务和股数有什么变化；
3. 悲观、基准、乐观情景的估值依据；
4. 最强的反面论据，以及哪项新事实会改变建议。

有持仓资料时，建议会改用持有、增持、减持等**有条件**的语言；没有你的成本、期限和组合信息时，不会假装知道你的个人情况。[查看完整报告契约 →](references/output-contract.md)

## 衡鉴如何判断

| 次序 | 核心问题 | 对结论的影响 |
| :--- | :--- | :--- |
| **01 · 定界** | 买到的是哪家公司、哪种证券？数据属于哪个时点？ | 身份或 ADR 比例未核实，暂停每股比较 |
| **02 · 验真** | 关键数字能否追溯到原始披露？期间与币种一致吗？ | 决定性事实冲突，建议等待核实 |
| **03 · 观势** | 生意、现金和资本配置是否支撑长期论点？ | 经营论点失效，价格再低也要重新判断 |
| **04 · 反照** | 最强的反面证据是什么？悲观损失能否承受？ | 正反论点按证据强度衡量 |
| **05 · 知止** | 价格有没有足够补偿？下一次检查什么？ | 给出一个行动建议和改变它的条件 |

建议形成遵循[同一套规则](references/recommendation-policy.md)：先排除身份与重大风险问题，再检查行业口径、来源和价格，最后比较上行与悲观下行。出稿前按[核验清单](references/report-qa.md)复算数字和检查反证。

## 行业有不同的尺子

| 类型 | 衡鉴优先关注 | 常见估值工具 |
| :--- | :--- | :--- |
| 一般盈利企业 | 资本回报、现金转换、再投资、债务 | 现金流情景、可比企业倍数 |
| 银行与保险 | 资产质量、资本与准备金、可持续 ROE | P/B、适用时 P/E |
| REIT | 物业运营、租约、债务期限与 FFO | P/FFO、NAV |
| 开发阶段生物科技 | 试验终点、监管进度、现金跑道与稀释 | 里程碑情景；证据不足时不硬算终值 |
| 持续亏损成长企业 | 单位经济、毛利、经营杠杆、现金消耗 | 有约束的业务情景与同业比较 |

[查看行业判断细则 →](references/sector-lenses.md)

## 思想来源，但不替任何人代言

衡鉴借鉴巴菲特／芒格对生意与股东现金的追问、霍华德·马克斯对风险补偿的重视、达摩达兰对叙事与数字一致性的要求，以及 Terry Smith 与 Bogle 对质量、价格和机会成本的提醒。道家「知止」与斯多葛的可控／不可控区分，落实为研究纪律。[投资方法视角](references/investor-lenses.md)与[衡鉴原则](references/hengjian-principles.md)给出一手出处和适用边界。

## 设计与边界

- **唯一交付物：** 一份建议单；搜索、计算和核验留在内部流程。
- **证据优先：** 关键数字标注来源、期间、币种和发布时间；未核实与已推翻分开。
- **清楚止步：** 缺少可靠价格或必要财务数据，仍出报告，建议降为「等待核实」。
- **不执行交易：** 不连接交易账户、下单、跟单或发布交易信号。
- **数据使用：** 港交所网站有自动抓取限制；港股研究优先使用公司投资者关系材料或其他可合法使用的来源。[数据规则 →](references/data-and-market.md)
