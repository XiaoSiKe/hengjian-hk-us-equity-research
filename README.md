# 衡鉴｜港美股投研

**给一个股票代码，得到一份有行动建议、有证据、也知道何时该改变判断的报告。**

衡鉴是面向港股、美股及 ADR／双重上市公司的 Agent Skill。它把公司研究、财报、估值、反面论证和风险复核整合进**一份「衡鉴建议单」**。报告首先回答「目前应该怎么想」，然后交代这个结论建立在什么事实与假设上。

`港股 / 美股 / ADR`　·　`中文优先`　·　`一份建议单`　·　`无需券商接入`

---

## 🧭 衡鉴解决什么问题

研究一只股票，很容易出现三种断裂：数字有来源却没有结论；结论很坚定却没有反证；企业看起来优秀，却没有问**当前价格已经包含了多少期待**。

衡鉴用「衡」和「鉴」处理这三件事：

| 字 | 在报告中意味着什么 | 读者能看到什么 |
| :--- | :--- | :--- |
| **衡** | 衡量生意、现金、价格与潜在损失 | 悲观／基准／乐观情景和对应的行动条件 |
| **鉴** | 查原始出处，也检查自己的判断 | 财报期间、币种、计算口径、最强反面证据 |

它不会让「多头观点三条、空头观点三条」自动打成平手；证据更强的一边应有更高权重。它也不会为了给出买入价而猜测报价、股数、汇率或临床试验成功率。


正常生成报告**不要求**设置券商账户、API Key 或市场数据服务。本仓库附带的 Python 工具是可选的内部计算器；运行条件不具备时，Skill 仍会使用当前可访问的披露与公开资料完成报告。

### 📝 只给一个代码

> 用衡鉴给我一份 AAPL 的建议单。

如果没有额外说明，衡鉴会按**一般权益投资者、12–36 个月研究期限、尚未提供持仓**处理，在报告开头写明这些默认前提。你指定投资期限或问题时，以你的要求为准。

### 📌 给出持仓或具体疑问

> 我持有 0700.HK，成本价是 HK$___。用衡鉴复核财报和持仓风险，告诉我继续持有需要哪些条件。

> 用 `$hengjian-hk-us-equity-research` 比较 BABA 与 9988.HK；先核实 ADS 比例与币种，再交一份综合建议单。

用户没有提供成本、仓位、期限或完整组合时，报告会标出哪些判断只能针对**股票本身**，不假装知道个人资产配置。

## 📄 最终交付：一份建议单

无论输入是「看看这只股票」、最新财报、一条群聊荐股消息，还是两地上市比较，最终都收束成**同一份报告**。搜索记录、脚本 JSON、安装步骤和内部质检清单不会混进正文。

```text
衡鉴建议单｜公司（交易所:代码）

研究截至 · 报价时点与币种 · 最近采用的财报期间 · 股类/ADR 关系

行动建议          可考虑买入 / 等待 / 回避 / 等待核实
建议适用范围      一般研究；或基于你主动提供的持仓条件
一句话理由        业务质量、当前价格与最大风险之间的关系
把握程度          高 / 中 / 低——衡量证据质量，不是上涨概率

01  生意与竞争：它如何赚钱，优势能否维持
02  财务与现金：增长是否转成现金，有没有债务或稀释压力
03  估值与价格：悲观、基准、乐观情景及关键假设
04  最强反面论据：哪项证据最可能证明当前建议是错的
05  改变建议的条件：行动触发点、止步点、下次复核事件
06  来源与边界：关键数字直达出处，标明时期和缺口
```

**建议先行，证据跟上。** 有足够数据时给可复核的情景区间；重要事实尚未核实时仍出完整报告，行动建议为「等待核实」，并指出**最值得补的一项证据**。报告的具体字段与详略见[输出契约](references/output-contract.md)。

## ⚖️ 衡鉴如何形成建议

### 五道研究关口

| 次序 | 要回答的问题 | 过不了这一关会怎样 |
| :--- | :--- | :--- |
| **01 · 定界** | 发行人、上市证券、ADR 比例和研究时点是否正确？ | 暂停每股或跨市场比较 |
| **02 · 验真** | 决定结论的财务数字有一手出处吗？期间与币种一致吗？ | 降级为「等待核实」 |
| **03 · 观势** | 商业机制、现金与资本配置是否支持长期论点？ | 核心论点已失效时考虑回避 |
| **04 · 反照** | 最强反证是什么？悲观情景的损失能否承受？ | 重新审视风险收益的方向 |
| **05 · 知止** | 当前价格补偿了多少风险？下一次要核查什么？ | 只给现有证据能支持的建议 |

### 四种新仓结论

| 建议 | 典型依据 | 报告会说明 |
| :--- | :--- | :--- |
| **可考虑买入** | 经营论点仍成立；价格低于基准情景；有依据的上行至少覆盖悲观下行 | 哪些假设成立时值得考虑，何种证据会使它失效 |
| **等待** | 企业可能不错，但当前价格、情景差距或悲观损失尚不合适 | 等待价格、财报或关键经营指标发生什么变化 |
| **回避** | 有已核实的重大永久性损失风险，或价格不低于可信的乐观情景 | 风险来源、为何低价不足以抵消风险 |
| **等待核实** | 身份、报价、币种或决定性资料缺失／冲突 | 哪一项资料最影响判断，核实后如何重算 |

这些是[建议形成规则](references/recommendation-policy.md)中的**条件**，不是保证未来收益的机械打分。持仓用户会得到相应的持有、增持或减持条件；缺少组合信息时，不会自动建议扩大仓位。

### 🧮 看价格，也看价格背后的预期

估值不是孤立的「目标价」。衡鉴会说明增长、利润率、再投资、折现率或行业倍数如何产生悲观／基准／乐观区间。有可靠价格和合适模型时，它还会反推**当前价格隐含了多高的增长要求**。

例如一个纯演示情景：现价 100、悲观价值 80、基准价值 130，则基准上行是 30，悲观下行是 20。这个 **30:20** 的关系只是进入下一步讨论的门槛；财务真实性、行业方法、竞争和尾部风险仍须分别核查。示例不是任何真实证券的估值。

## 🧩 行业有不同的尺子

一套普通企业自由现金流模型无法覆盖所有公司。衡鉴会先确认商业模式，再决定该看什么：

| 公司类型 | 重点证据 | 应避免的套用 |
| :--- | :--- | :--- |
| **一般盈利企业** | 资本回报、利润到现金的转换、再投资与债务 | 只因 P/E 低就称为便宜 |
| **银行** | 存款成本、净息差、贷款质量、拨备、CET1 与流动性 | 把存款当普通企业债务，机械使用 FCFF/EV |
| **保险** | 承保质量、准备金、投资资产及法定资本 | 把财险综合成本率套给寿险 |
| **REIT** | FFO、物业经营、租约、维护支出、分派与再融资 | 只用 GAAP 净利润或未核对的 AFFO |
| **开发阶段生物科技** | 试验终点、监管里程碑、现金跑道和稀释 | 把早期项目预测成稳定终值 |
| **持续亏损成长企业** | 留存与单位经济、毛利、经营杠杆、现金消耗 | 假设负现金流会自行转正 |

完整核查项、方法适用边界及指标出处放在[行业判断](references/sector-lenses.md)。混合集团按业务拆解；两地上市先做 ADR 与汇率换算，再比较同一经济权益。

## 🔎 资料从哪里来，如何处理冲突

**先看原始披露。** 美股优先核 SEC 申报及公司投资者关系材料；港股优先核公司发布的年报、业绩公告和演示材料。报价必须说明**市场、币种、盘中／盘后／收盘与时间**。新闻、券商观点和社交帖子可提供线索，不能把未核实叙述升级成事实。

每项决定结论的数字都要保留五件事：**来源、公布时间、财务期间、单位、币种**。同比、FCF、每股估值等派生数字还要能从输入重算。若两个可信来源不一致，报告会并列差异与可能的口径原因；「没有核实」与「已经证伪」也会分开写。[证据审查方法 →](references/evidence-review.md)

数据源不应让使用者承担配置工作。已有的只读工具可帮助取数；工具不可用时换用可直接访问的材料。出于[港交所网站条款](https://www.hkex.com.hk/Global/Exchange/Terms-of-Use?sc_lang=en)的限制，本 Skill 不编写或指导对该网站的自动抓取与文本数据挖掘。[详细数据规则 →](references/data-and-market.md)

## 📚 大师视角与哲学纪律

衡鉴会从与公司问题相关的视角中挑选少数提问方式：巴菲特／芒格关注企业质量和股东现金，霍华德·马克斯追问风险补偿，达摩达兰要求叙事与数字互相约束，Terry Smith 和 Bogle 提醒价格、耐心与机会成本。它**不模拟大师发言，也不让名人替具体股票投票**。[一手材料与适用边界 →](references/investor-lenses.md)

道家「知止」与斯多葛的可控／不可控区分被用作研究纪律：能够控制的是来源核验、假设、组合暴露与复核；短期股价结果仍有不确定性。哲学帮助发现盲点，财务和市场判断仍由当期证据决定。[衡鉴原则 →](references/hengjian-principles.md)

## ❔ 常见问题

**只有代码，没有持仓信息，也能出报告吗？** 能。报告采用一般研究视角和默认期限，并明确哪些结论依赖个人情况。

**没有最新报价怎么办？** 仍交付建议单；不计算与现价相关的收益率、买入区间或精确目标价，建议写「等待核实」。

**可以分析美股 ADR 和对应港股吗？** 可以。先核对存托比例、交易币种和报告币种，再换算同一普通股经济权益，不直接比两个代码的股价。

**要连接券商或让它自动交易吗？** 不需要，也不会。衡鉴只研究并形成有条件的建议，不下单、跟单或发布交易信号。

**支持 A 股、加密资产或期权策略吗？** 当前主流程聚焦港美上市公司股票及 ADR；这些市场和工具不套用本 Skill 的股票建议规则。
